# Hello World

```c
// 我是注释
#include <stdio.h> // 预处理指令，stdio标准输入输出库，h表示头文件，<>系统路径，”“先当前后系统路径

int main(void) // 主函数，程序入口，一个程序有且仅有一个
{
    printf("Hello, World!");  // 调用printf函数，输出字符串
    return 0; // 结束并返回值，0表示正常结束
}
```

# 程序基础

## 源程序

- 一个源程序可以由一个或多个源文件组成
- 一个源文件可以由一个或多个函数组成
- 一个源程序有且仅有一个main函数，并从main函数开始执行，main函数位置随意
- 源程序的基本单位为函数

## 注释

方便阅读理解程序，注释不会被编译

```
// 单行注释
/* */ 多行注释
```

## 执行流程

```
.c => 预处理、检查编译、汇编 => .obj => 可执行程序
```

.c不能直接编译运行为可执行程序

## 组成

由标识符、关键字、运算符、分隔符、常量、注释符等组成

## 提示

警告：能正常运行，但可能有错误，结果不符合预期
错误：不能编译通过

## 常量

不允许改变值的量

### 分类

- 整型常量
- 实型常量
- 字符型常量
- 字符串常量
- 符号常量

### 整型常量

```c
012
123
0x123
123L
123U
```

- 八进制：0开头，无符号，0-7
- 十进制：无前缀
- 十六进制：0x/0X开头，0-f
- 后缀L/l表示长整型
- 后缀U/u表示无符号

### 实型常量

```c
1.23
1.23e-4
```

又称实数、浮点数，c的实数概念和数学不同
分十进制形式和指数形式
“-.1”、“1.”合法，“."不合法
指数形式（aEn）的n为整数，a和n都必须有值

### 字符型常量

```c
'a'
```

分普通字符和转义字符
一个字符占一个字节，常用ASCII码

#### 关键ASCII码

```c
'\0' 0
'0'  48
'a'  97
'A'  65 // 差32
' '  32
'\n' 10
```

了解：0-31为控制字符，32-126为可显示字符，127为DEL

### 转义字符

由反斜杠“\”开头，具有特定含义

```c
'\''   单引号
'\"'   双引号
'\\'   反斜杠
'\a'   警告声
'\b'   退格
'\f'   换页
'\n'   换行
'\r'   回车
'\t'   水平制表符
'\v'   垂直制表符
'\101' 1-3位并为八进制数，字符类型，相当于字符‘A’
'\x41' 1-2位并为十六进制数，字符类型，相当于字符‘A’
```

### 字符串常量

```c
"a"
```

由双引号括起来的字符序列，区别于单引号的字符型常量
可以包含多个字符及转义字符
占用为字符数量+1个字节，末尾自动加'\0'

### 符号常量

```c
#define PI 3.14
```

用#define定义的常量
一般需规范大写符号常量
和#include一样是预处理指令/宏定义，指令末尾不加;

## 变量

允许改变值的量
先声明后使用

### int

```c
int
unsigned int
```

int 声明有符号整型变量,相当于 signed int
unsigned int 声明无符号整型变量

#### 范围

声明的值根据字节大小有范围限制
变量溢出时，丢失高位数据

### char

```c
char
```

char 声明字符型变量
赋值字符时，保存对应ASCII码值，'1'+'1'为对应ASCII码值相加
本质为只占一个字节的有符号整型变量

### 浮点型

```c
float
double
```

float、double、long double 声明浮点型变量
实型常数默认为double型, 打印保留小数点后6位

### 常变量

```c
const
```

const 声明常变量
有类型，开辟空间，不可修改
符号常量不开辟空间

### Undefined Behavior

```c
int a
```

声明变量后未初始化
值为开辟的空间遗留的随机值

## 标识符

```c
int a, A, _a1
```

变量名、函数名、数组名、类型名、文件名等
由字母、数字、下划线组成，不能以数字开头
区分大小写
长度不超过31个字符，实际有效长度为31
关键字不能作为标识符

# 运算符

有1-15优先级
括号 > 类型转换 > 算术运算 > 赋值运算 > 逗号运算

## sizeof

获取占用字节数

## 算术运算符

```c
+
-
*
/ // 参数都为整型，结果为整型，整型除法向下取整
% // 参数必须都为整型
++ // 只能用于变量
--
```

只有++--会改变值本身

## 类型转换

```c
(int)a
```

## 逗号运算符

```c
a = b, c // a 的值为 b
```

返回最后一个表达式的值
比赋值=优先级低

## 赋值运算符

```c
int a = 1
```

将后面的值赋给前面的变量
不能赋值给常量和表达式
自动类型转换

### 复合赋值运算符

```c
a *= b + c // 相当于 a = a * ( b + c )
```

快速计算：a += a 相当于 a x 2，a -= a 相当于 0，a \_= a 相当于 a^2

## 表达式

由运算符、操作数组成的式子
表达式含浮点数，结果为double型
char和int运算，char会转ASCII码值

c 语言没有输入输出语句
导入stdio.h库实现

## printf

以指定格式输出数据

```c
printf("格式控制字符串", [a]);
```

### 格式控制字符串

由格式字符和格式声明符组成
格式声明符需有对应参数，否则输出不符合预期

```c
// 格式声明符
%d  // 十进制整型
%md // 指定宽，m正数前补，负数后补
%ld // 长整型
%c  // 字符型
%f  // 浮点型
%m.nf // 指定宽，n小数点后位数
%o  // 八进制
%x  // 十六进制
%#x // 带前缀0x
%u  // 无符号整型
%s  // 字符串
%p  // 指针
%e  // 指数
%g  // %f和%e
%%  // 输出%
```

## scanf

以指定格式输入数据到变量
需按格式输入格式字符
参数需要地址，要使用取址符&
%f只能赋值给float，%lf只能给double
%mc会匹配m个字符
没有%m.nf

```c
scanf("格式控制字符串", &a);
```

## putchar

输出单个字符，接收 int 类型参数

```c
putchar(97);
```

## getchar

输入单个字符，返回 int 类型参数

```c
a = getchar();
```

后续会从缓冲区直接读取
